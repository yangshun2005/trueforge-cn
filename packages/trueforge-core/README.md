# @truefoundry/trueforge-core

[文档](https://trueforge.dev) · [npm](https://www.npmjs.com/package/@truefoundry/trueforge-core) · [GitHub](https://github.com/truefoundry/trueforge)

这是 [TrueForge](https://trueforge.dev) 背后的智能体执行库：负责运行智能体循环的运行时 — 包括模型调用、MCP 工具、技能、沙箱、审批、上下文管理和会话状态。

## 改用 TrueForge

此包是 TrueForge 服务器所基于的库。它**并非**一个完整的产品。

如果你需要 HTTP API、TypeScript SDK 和聊天界面，请使用 [`@truefoundry/trueforge`](https://www.npmjs.com/package/@truefoundry/trueforge)，并从 **[trueforge.dev](https://trueforge.dev)** 开始。

```bash
npx @truefoundry/trueforge
```

- [快速入门](https://trueforge.dev/quickstart)
- [HTTP API 与 SDK](https://trueforge.dev/api/overview)
- [聊天界面](https://trueforge.dev/chat-ui)

## 兼容性

`@truefoundry/trueforge-core` 目前**不**提供向后兼容性保证。公共 API 和类型可能在任何版本中发生变化。如果你依赖此包，请锁定精确版本。
