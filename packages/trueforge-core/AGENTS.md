# 工作区源码必须保持 ESM 格式，以便 `exports["trueforge-dev"]` 无需构建即可加载 `src/`。该条件名称不得为 `"development"`（或 `"production"`）——该包从自身根目录发布，并带有 `files: ["dist", "README.md"]`，因此 `src/` 永远不会包含在 tarball 中，且 Vite/webpack 默认会在开发模式下自动激活字面意义上的 `"development"` 条件，无需消费者选择加入，这会导致任何此类消费者的解析失败。`dist/` 输出必须同时提供 CJS `.js` 和 ESM `.mjs` 输出，以及 `.d.ts` 文件。
# 顶层公共包接口（`core`、`agent-session` 及其他导出的入口点）可以使用可选（`?`）属性以提升调用方的便利性。
# 在此包内部，记录、快照、存储输入类型及其他内部契约不得使用 `?`。缺失必须显式表示为必填的 `| null` 或 `| undefined` 字段；领域缺失优先使用 `null`，仅当更新/补丁语义需要区分“未提供”和“清除”时才使用 `undefined`。公共接口在向内调用时通过提供这些显式缺失来进行适配。这强制内部对象字面量在 `tsc` 下保持穷尽性，防止遗漏字段和静默数据丢失。
